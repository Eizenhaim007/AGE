# AGE website

Use [the brand guidelines](docs/brand-guidelines.md) and `src/styles/tokens.css` for visual and interaction changes. French and English share the same services, project taxonomy, and inquiry behavior. Keep section anchors and public routes stable.

Run `npm run build` and `npm test` before opening a pull request. Review layout changes at mobile and desktop widths. Test form submission against a separate Netlify staging project with a test recipient.
